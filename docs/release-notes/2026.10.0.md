# Release 2026.10.0

## Portal

- Add a Markdown preview tab to the log entry editor.
- Add the ability to maximize the log entry editor.
- Add an All Logbooks page for viewing and filtering log documents across every logbook type.
- Add a default owner group setting for each logbook type. New log documents inherit the configured owner group.
- Improve logbook selection and document lists with hierarchy-aware names and filtering.
- Prevent creating log documents from top-level logbook groupings.
- Apply stricter attachment type handling and provide browsers with safer display and download instructions.

## API

- Add endpoints to create log entry replies.
- Add endpoints to delete log entries, attachments, document sections, and log documents.
- Add an endpoint for fetching the logbook type hierarchy.
- Exclude top-level logbook groupings from the list of types valid for new documents.
- Add authentication endpoints for login, logout, and token verification.
- Include attachment IDs in log entry responses to support attachment removal.

## BELY CLI and TUI

The new BELY CLI and terminal interface are available from PyPI:

```bash
pip install bely-cli
```

- Add the `bely-cli` command-line client for creating, browsing, and deleting log documents; adding, updating, deleting, and replying to log entries; and listing, uploading, and deleting attachments.
- Add a Textual terminal interface with support for:
  - Browsing and filtering logbooks, documents, entries, replies, and attachments, with rendered Markdown previews and collapsible reply threads.
  - Creating and deleting documents and managing entries and replies, with additional confirmation for destructive actions.
  - Browsing, previewing, uploading, and deleting attachments, with directory filtering and upload progress feedback.
  - Detecting Markdown images and optionally displaying them inline in supported terminals.
  - Editing entries in an external editor.
  - Navigating to previous and next entries.
  - Logging in and out using the same cached authentication as the CLI.
  - Editing configuration and retaining theme selection.
- Add shell completion with cached suggestions for identifiers and other dynamic values.
- Add conventional command aliases such as `ls`, `show`, and `update`.
- Add cached authentication with login, logout, token verification, and configurable cache expiration.
- Add shared and user-specific configuration with environment variable overrides.
- Add text, JSON, and YAML output formats for command-line use and automation.
- Add external editor support and the ability to read entry text from standard input.
- Add commands for showing document and entry details, with file and standard-output options.

## MCP Integration

- Add a read-only Model Context Protocol (MCP) endpoint for AI clients.
- Add MCP tools to:
  - Search BELY.
  - List and fetch log documents and entries.
  - List logbook types and systems.
  - List users and user groups.

## Performance and Compatibility

- Improve search performance on MariaDB 10.5 by avoiding an inefficient join plan. Server testing reduced affected searches from approximately 255 seconds to less than one second.
- Update Python components to Python 3.13.
- Update stored password hashing to PBKDF2-HMAC-SHA512 while retaining compatibility with existing passwords.
- Add lazy imports to the Python API client to improve command startup time.

## Packaging and Development

- Add PyPI and conda packaging for `bely-api`, `bely-cli`, and `bely-mqtt-framework`.
- Add unified tooling for preparing BELY releases and publishing Python packages.
- Add automated Java portal and BELY CLI tests to GitHub Actions.

## Bug Fixes

- Fix logbook filtering and previous/next navigation when viewing all documents.
- Fix blank screens when returning from or leaving a full-screen entry in the TUI.
- Fix hidden filters in TUI logbook and document selection screens.
- Fix selection indicators when choosing multiple systems in the TUI.
- Fix external editor changes not being detected when updating an entry.
- Fix TUI scrolling so the selected entry retains its position and newly selected entries start at the top.
- Fix authentication errors when a username does not exist.
- Fix searches containing double quotation marks.
